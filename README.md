# 🎬 Movie Rating App (React)

A simple and interactive **Movie Rating App** built using **React.js**. Users can add movies, rate them, view details, and manage their movie collection.

## 🚀 Features

- ➕ Add new movies  
- ⭐ Rate movies (1–5 stars)  
- 📋 View movie list  
- 📖 View movie details  
- 💾 Data stored in localStorage  
- 🎨 Simple and clean UI  

---

## 🛠️ Tech Stack

- React.js  
- Vite  
- JavaScript (ES6)  
- CSS  

---

## ⚙️ Installation & Setup

1. Clone the repository  
   git clone https://github.com/your-username/movie-rating-app.git  

2. Install dependencies  
   npm install  

3. Run the app  
   npm run dev  

---

## 📌 Functionality Breakdown

### ➤ Add Movie
- Input: Title, Description, Rating  
- Saves to state + localStorage  

### ➤ Movie List
- Displays all movies  
- Shows ratings  

### ➤ Movie Details
- Full description view  
- Back navigation
